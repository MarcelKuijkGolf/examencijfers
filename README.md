# Examencijfers TL4

Rekenhulp voor het schoolexamen (SE) en centraal examen (CE) van vmbo TL, cohort 2025-2027, Ichthus College Dronten.

- Wegingen komen uit het PTA versie 003 (24-09-2026).
- Per vak: SE cijfer, benodigd CE cijfer voor een 5, 6 of 7, en de verwachte uitslag volgens de slaag/zakregeling vmbo TL.
- Cijfers worden alleen in de eigen browser opgeslagen. Er gaat niets naar een server.

Het officiële examenreglement van school is leidend.
